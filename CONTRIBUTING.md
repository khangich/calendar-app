# Contributing

Thanks for helping! PRs welcome.

### Quick dev

```bash
npm install
npm test   # 35 tests
npm start  # Electron
```

### What to work on

- Search, type editing, `userData` fix just landed — see PR #1
- Good next issues: drag-drop move, week view, import/export

### PR process

1. Fork, branch `fix/...` or `feat/...`
2. `npm test` must pass
3. Update README/docs if user-facing
